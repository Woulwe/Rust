# Rust PC Search — Woulwe

Адаптивная русскоязычная страница для поиска актуальной информации о Rust для Windows.

## Файлы
- `index.html` — готовый сайт без сборки и внешних зависимостей.

## Запуск
Откройте `index.html` в браузере или включите GitHub Pages:
1. Settings → Pages.
2. Build and deployment → Deploy from a branch.
3. Branch: `main`, folder: `/ (root)`, затем Save.

## Важно
Сайт открывает поиск в Google, Bing или DuckDuckGo и содержит ссылки на официальные страницы Rust. Он не загружает сторонние игровые сборки, не предоставляет пиратские копии и не может подтвердить безопасность файла только по результатам поиска.
